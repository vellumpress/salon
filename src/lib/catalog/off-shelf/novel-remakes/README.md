# OFF-SHELF — novel-length Adapted remakes

These eleven bound sits are **not on the live shelf**. Mike’s 20 Sep rule:
Adapted is short stories only, about fifteen minutes or less. Novel remakes
stay in this folder so the text is not destroyed, and they are not imported
by the reader (`catalog/texts` and `catalog/openings` globs are one level
deep).

Do not move these JSON files back to `src/lib/catalog/texts` or
`src/lib/catalog/openings`, and do not add their ids to `shelf.ts`.
